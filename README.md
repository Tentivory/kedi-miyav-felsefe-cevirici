## Bu Nedir?

Bu, insanlık tarihinin en önemli icadıdır. Kedilerin "miyav"larını, derin, varoluşsal, abartılı Türkçe felsefi cümlelere çevirir. Artık kedinizin "açım" demek yerine "varlığın anlamsızlığı karşısında mama kasesinin boşluğu beni sorgulatıyor" dediğini duyabilirsiniz.

Bilim bunu reddetti. Felsefeciler ağladı. Kediler umursamadı.

## Nasıl Kullanılır?

```bash
python3 kedi_cevirici.py
```

Sonra miyav sayısını girin. Veya rastgele bırakın. Kediler zaten rastgeledir.

## Özellikler

- Gerçekten çalışır (test ettik, kediler onayladı veya onaylamadı)
- Abartılı Türkçe cümleler üretir
- Hiçbir mantığı yoktur ama ciddi görünür
- Gizli mesajlar içerebilir (içermeyebilir)
